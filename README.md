## Project Description
Project Description
Kujola is a story-driven, third-person survival-adventure game set in a post-apocalyptic, water-submerged version of Bangladesh. The game follows Rivan Ray, a lone survivor whose wife was brutally murdered and his robot companion destroyed by savage scavengers. As he journeys through this hauntingly beautiful drowned world, Rivan seeks vengeance while uncovering the truth behind the collapse of civilization.

🌊 Core Themes & Setting
The world of Kujola is inspired by the rural and urban landscapes of Bangladesh, now overtaken by rising seas, decaying buildings, overgrown vegetation, and lawless factions.

The game explores loss, survival, revenge, and the remnants of humanity in a future shaped by climate disaster and moral decay.

Environmental storytelling plays a key role—abandoned homes, wrecked boats, sunken markets, and flooded temples provide context without exposition.

🧭 Gameplay Overview
Exploration & Survival: Players navigate through flooded villages, jungle swamps, and broken infrastructures using swimming, climbing, and boat traversal.

Combat System: A mix of melee and ranged combat, with equippable tools like axes, makeshift firearms, and gauntlets. Enemies include scavengers, mutated amphibians, and corrupted humans.

Crafting & Equipment: Players collect materials to craft gear, build items, and enhance weapons. An in-game recipe book UI allows for intuitive crafting.

Inventory & Equipment System: An integrated UI system allows for storing, equipping, dropping, and using items. Equipped items appear visually in Rivan’s hands.

Mini-games & Hacking: Terminals scattered across the world unlock clues and data through binary manipulation mini-games, pausing the world while solving.

Honor System: Key actions such as sparing enemies or completing hidden quests grant "honors" which unlock access to special items, locations (like the Raft of Drowned God), and dialogue options.

🧠 Narrative Depth
Kujola is not just a game about survival—it is a character-driven journey. Rivan constantly interacts with remnants of his past life through flashbacks, voiceovers, and environmental clues.

The game features a layered main quest supported by side missions that reveal the fate of society, the origin of the toxic creatures, and the emergence of scattered survivor factions.

Four major missions unfold Rivan's personal arc—from gathering clues about his wife’s death to confronting the warlord responsible.

🎮 Technologies Used
Developed in Unity 2022 LTS

Models created in Blender

Voice editing via Audacity

Motion and combat animations via Mixamo

Version control using GitHub + Git LFS

UI crafted with TextMeshPro and Unity UI Toolkit
